CSS Overflow Properties

overflow: visible

This is a long paragraph. When the content is larger than the box, it can extend outside the boundaries of the element.

overflow: hidden

This is a long paragraph. Extra content is clipped and cannot be seen outside the boundaries of the box. More text is added to demonstrate the hidden overflow.

overflow: scroll

This is a long paragraph. Scrollbars are always displayed, allowing the user to scroll through the content inside the box. Additional content is included here.

overflow: auto

This is a long paragraph. Scrollbars appear only when the content exceeds the available space inside the box. This demonstrates automatic overflow handling.
