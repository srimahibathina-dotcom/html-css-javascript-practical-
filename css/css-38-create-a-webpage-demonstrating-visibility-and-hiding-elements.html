CSS Visibility and Hiding Elements

Visible Element

The green element uses visibility: visible.

Hidden Element

The red element uses visibility: hidden. Its space is still preserved.

Display None

The blue element uses display: none. It is completely removed from the layout.

Transparent Element

The purple element uses opacity: 0. It becomes invisible, but its space is preserved.

Summary:

visibility: visible → Element is visible.
visibility: hidden → Element is hidden, but space remains.
display: none → Element is hidden and takes no space.
opacity: 0 → Element is transparent, but space remains.
