CSS Object-Fit and Object-Position

object-fit: fill

The image stretches to fill the given width and height.

object-fit: contain

The complete image is displayed without cropping.

object-fit: cover

The image covers the entire box and may be cropped.

object-fit: none

The image keeps its original size.

object-position: top

The image is positioned at the top of the container.

object-position: bottom right

The image is positioned at the bottom-right.
